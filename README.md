# MH Wilds 素材トラッカー

モンスターハンターワイルズの素材・護石・装飾品・武器・防具の一覧と、モンスター別ドロップ率、人ごとの「欲しいものリスト」から必要素材を自動計算する非公式ファンツールです。

GitHub Pages の静的ページだけで動くので費用は0円です（サーバー・DB・有料APIなし）。

## 機能

- **欲しいもの**: 武器・防具・護石タブで「＋欲しい」を押すと、必要な素材とお金を自動で合計。所持数を入れると残り数を計算。武器は「生産から全部」で派生元の強化素材もまとめて計算。
- **装備シミュ**: 武器・防具5部位・護石を選び、各スロットに装飾品を付けると、発動スキル（レベル・効果・どこから付いたか）、シリーズスキル/グループスキルの発動状況、攻撃力・会心率・属性・防御力・耐性、必要素材をまとめて表示。
  - アーティア武器はスキルを手動で追加でき、攻撃力・会心率・属性（種類と値）・スロットをゲーム画面に合わせて入力可能。防御力も強化後の値を入力できる。巨戟アーティアはシリーズスキル・グループスキルを選択（武器を1部位分として数える）。
  - 護石は固定の護石のほか「鑑定護石（カスタム）」でスキルとスロット（武器/防具・Lv）を自由に設定。
  - 組み合わせは名前を付けて保存でき、共有URLにも含まれる。「欲しいものに全部追加」で必要素材の集計へ。
- **武器 / 防具 / 護石 / 装飾品 / 素材**: 名前・スキル・素材名・モンスター名で検索。素材には入手先と使い道を表示。
  - 武器は「派生ツリー順 / モンスター別 / 属性別」で分類表示、モンスター・属性で絞り込み可能。
  - 防具・素材には下位/上位のバッジを表示し、ランクで絞り込み可能（防具は下位→上位の見出しで表示、素材は各分類の中で下位→上位の順）。
  - 防具には最大強化までの強化ポイント・費用・鎧玉の数（重鎧玉5000pt / 堅鎧玉1000pt / 尖鎧玉200pt / 上鎧玉50pt / 鎧玉10pt、大きい順に計算）を表示。欲しいもので「最大まで強化」にすると金額と鎧玉も集計に入る。装備シミュにも合計を表示。
  - 防具名を押すと詳細画面が開き、耐性・スキル効果・生産素材・強化の段階表（Lvごとの防御力・ポイント・費用・累計）・限界突破を表示。限界突破は `data/armor-limit-break.json` の `byRarity` にレア度ごとの段階（step / def / zenny / materials: {素材名: 個数} / note）を登録すると表示される。
  - モンスターは種族ごとのオリジナルのシルエットアイコンで表示。
  - 素材は大型モンスターごと（ハンターノート順）→ 複数モンスター共通 → 鉱石・結晶 / 骨 / 袋・体液 / 小型モンスター・環境生物 / 虫・ハチミツ / 食材・植物・卵 / 鎧玉 / チケット・コイン・証 / その他 に分類。
- **モンスター別ドロップ**: モンスターごとに、下位/上位・入手方法（剥ぎ取り・報酬・部位破壊・傷破壊など）別の素材と確率、弱点を表示。自分に足りない素材はハイライト。
- **巨戟アーティア**: 巨戟アーティア武器に付くシリーズスキル（2部位／4部位）・グループスキル（3部位）の一覧（説明文は要約）。同じスキルを持つ防具シリーズも表示。データは `data/gogma-artian-skills.json`。
- **採取ガイド**: 採掘（鉱脈）・骨塚・虫・植物/キノコ・特産品・釣り・モンスター限定素材を、マップ（（上）/（下）付き）・エリア・メモで一覧。マップで絞り込み、自分に足りない素材は「あと○」を表示。素材タブの入手先・行くマップにも採取場所を表示。データは `tools/gathering-source.py` から `data/gathering.json` を生成（ユーザー提供の情報を整理したもの）。
- **出現マップ**: モンスターの出現マップ（隔ての砂原・緋の森・油涌き谷・氷霧の断崖・竜都の跡形）を表示し、マップでモンスターを絞り込み可能。素材には落とすモンスターの出現マップ（行くマップ）を表示。
- **弱点**: モンスター別ドロップに属性（火・水・雷・氷・龍）の効きやすさ（◎○▲×無効）を表示し、「弱点早見表」で全モンスターを一覧。モンスター一覧には◎の属性アイコンを表示。データは `data/monster-weakness.json`（ユーザー提供の早見表から入力）。
- **限界突破**: 上位防具（レア5〜8）の限界突破（1回だけ・上限Lv、上がる防御力、スロットの増え方、費用、素材の形、追加で必要な鎧玉）を防具タブ・詳細画面・欲しいもの・装備シミュで表示。内容は `data/armor-limit-break.json`。
- **人ごとのリスト**: 「だれのリスト？」で人を追加・切り替え。各自のブラウザ（localStorage）に保存。
- **共有**: 「共有URLをコピー」で送ったURLを開くと、そのリストを取り込めます（スマホ⇔PCの引っ越しにも）。
- **みんな**: 登録した全員の足りない素材をモンスター別にまとめて表示。

## 公開方法（GitHub Pages）

Settings → Pages → Build and deployment で「Deploy from a branch」、Branch を `main` / `/(root)` にして Save。

## データの更新

データは [MHDB (mhdb-wilds-data)](https://github.com/LartTyler/mhdb-wilds-data) から生成した `data/mh-wilds.json` です。ゲームのアップデート後は次で更新できます。

```sh
git clone --depth 1 https://github.com/LartTyler/mhdb-wilds-data.git
python3 tools/build-mh-wilds-data.py mhdb-wilds-data/output/merged
```

MHDB に含まれない情報（採取・交易での入手、アーティア武器の生産ボーナス等）は表示されません。

## 更新を公開するとき

ブラウザに古いファイルが残らないよう、`index.html` の `?v=...` と `assets/app.js` の `VERSION` を同じ新しい値（例: 日時）に変えてから push してください。
